## NotebookLM Integration

When working with unfamiliar libraries, APIs, or technologies:
1. Check for a relevant NotebookLM notebook via `notebook_list`
2. Use `notebook_query` for grounded answers with citations from loaded documentation
3. Do not rely solely on training data when NotebookLM has the documentation loaded
4. When creating a new project — suggest creating a NotebookLM notebook with stack documentation
