# /youtube-research — Анализ YouTube видео через NotebookLM

Замена YouTube transcript API (который даёт 429). NotebookLM нативно принимает YouTube-ссылки как источники и извлекает контент.

## Параметр
$ARGUMENTS — тема исследования

## Действия

1. Спроси у пользователя список YouTube-ссылок (1-10 видео)
2. Создай NotebookLM ноутбук "YT Research: $ARGUMENTS" через `notebook_create`
3. Добавь каждую YouTube-ссылку через `source_add`:
   - `source_type`: "url"
   - `wait`: true (дождаться обработки каждого)
4. После загрузки всех источников выполни `notebook_query`:
   - "Какие ключевые идеи и концепции обсуждаются в этих видео?"
   - "Составь структурированное резюме по каждому видео отдельно"
5. Если пользователь задал конкретный вопрос в $ARGUMENTS — задай его тоже через `notebook_query`
6. Выведи результат:
   - Общий обзор темы
   - Резюме по каждому видео (с цитатами из источников)
   - Ключевые выводы и паттерны
   - Рекомендации к действию
7. Предложи: "Сгенерировать Audio Overview (подкаст) из этого ноутбука?"
   - Если да — `studio_create` с `artifact_type=audio`, `confirm=true`
