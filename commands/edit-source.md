# /edit-source — Редактирование источника в NotebookLM

NotebookLM API не поддерживает прямое редактирование источников. Эта команда обходит ограничение: извлекает контент, позволяет отредактировать, удаляет старый и создаёт новый.

## Параметр
$ARGUMENTS — название ноутбука или notebook_id

## Действия

### Шаг 1: Выбор источника

1. Получи список источников через `notebook_get` для указанного ноутбука
2. Покажи пользователю пронумерованный список источников с типом и названием
3. Спроси какой источник нужно отредактировать

### Шаг 2: Извлечение контента

4. Получи содержимое через `source_get_content` по source_id
5. Покажи пользователю текущий контент (или первые 500 символов если большой)
6. Сохрани: source_id, title, полный текст

### Шаг 3: Редактирование

7. Спроси пользователя что нужно изменить. Варианты:
   - **Заменить текст**: "замени X на Y"
   - **Добавить текст**: "добавь в конец/начало: ..."
   - **Удалить часть**: "удали абзац про X"
   - **Полная замена**: пользователь вставляет новый текст целиком
8. Примени изменения к полному тексту

### Шаг 4: Замена источника

9. Покажи превью изменённого контента (первые 500 символов + diff если возможно)
10. Спроси подтверждение: "Заменить источник? Старый будет удалён."
11. Если да:
    - Удали старый: `source_delete` с `source_id` и `confirm=true`
    - Создай новый: `source_add` с `source_type=text`, `title` (оригинальное название), `text` (изменённый контент), `wait=true`
12. Покажи результат: "Источник обновлён. Новый source_id: ..."

## Ограничения
- Работает только с текстовыми источниками (`source_type=text`)
- Для URL/YouTube/файловых источников: контент можно извлечь через `source_get_content`, но при замене тип станет `text` (теряется привязка к URL)
- Для Google Drive источников лучше: отредактировать документ в Drive → `source_sync_drive`

## Для Drive-источников (альтернативный путь)
Если источник из Google Drive:
1. Сообщи пользователю: "Этот источник из Google Drive. Отредактируй документ в Drive, затем я синхронизирую."
2. Дождись подтверждения
3. Выполни `source_sync_drive` с `source_ids` и `confirm=true`
